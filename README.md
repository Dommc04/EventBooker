# 🍷 Mixer EventBooker

A desktop event booking application for managing events and RSVPs.

## 📥 Downloads

### Windows
- [Installer (Recommended)](https://github.com/Dommc04/EventBooker/releases/download/v1.0.0/Mixer.EventBooker.Setup.1.0.0.exe)

## ✨ Features
- Create and manage events
- Track RSVPs with guest counts
- Dark/Light mode toggle
- Local SQLite database
- No internet connection required

## 🚀 Quick Start
1. Download the installer
2. Run `Mixer EventBooker Setup 1.0.0.exe`
3. Follow installation wizard
4. Launch from Start Menu
5. Enter your name and start creating events!

## 🛠️ Tech Stack
- React 18
- Express.js
- SQLite
- Electron
- Vite

## 📦 System Requirements
- Windows 10 or later
- No additional software required (Node.js bundled)
